# Word & Character Counter

Live word count, character count, sentence count, and reading time estimate. Runs entirely in your browser.

**Live:** <https://word-counter.slippylabs.com/>

## What it does

- Word, character, sentence and paragraph counts, updating as you type.
- Estimated reading time alongside the counts.

## Run it locally

A static site. No build step, no package manager, no dependencies:

```
git clone git@github.com:slippylabs/word-counter.slippylabs.com.git
cd word-counter.slippylabs.com
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
